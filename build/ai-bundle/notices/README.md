# Candor Local AI Notices

This source build contains the bundled-asset interface but does not contain or
claim to contain release AI binaries or model weights.

Before `releaseReady` may be set to `true`, the staged bundle must include a
license file for every runtime, library, and model, plus a model card for every
model. The strict bundle verifier rejects missing notices, missing files,
placeholder hashes, unapproved redistribution, and fixture manifests.

Current upstream references:

- whisper-rs: https://codeberg.org/tazz4843/whisper-rs
- whisper.cpp: https://github.com/ggml-org/whisper.cpp
- llama.cpp: https://github.com/ggml-org/llama.cpp

No default instruction model has been selected.
