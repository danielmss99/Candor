## Expected strict failure

`npm run spec3:ai-bundle:verify:strict` fails by design. A strict Complete
release requires a selected Whisper model, selected llama.cpp runtime, selected
LLM, real digests, redistribution approval, model cards, notices, and a
non-fixture release manifest. None were fabricated.

## Release blockers

- No default LLM has completed redistribution review, provenance review,
  benchmark selection, or meeting-quality evaluation.
- No real bundled AI files are present, so the release SBOM correctly reports
  zero bundled AI packages.
- Windows artifacts are unsigned. macOS and Linux release artifacts were not
  produced in this Windows run.
- Cross-OS packaged network-deny evidence is incomplete.
- Clean-install, upgrade, corruption-repair, and 8/16/32 GB hardware evidence is
  incomplete.
- Physical 5, 30, 60, and 180-minute recording, transcription, and recap runs
  remain incomplete.

This verifies the source boundary and Windows package behavior. It does not
declare the Complete public beta release-ready.
